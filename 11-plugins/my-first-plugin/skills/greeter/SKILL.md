# Greeter Skill

When invoked, write a short, warm greeting for the named person.

## Steps
1. Take the person's name from the request (ask if none was given).
2. Write a one or two sentence greeting that uses their name.
3. Keep the tone friendly and professional.

This skill ships inside `my-first-plugin` to show that a plugin can bundle a skill, not just commands.
