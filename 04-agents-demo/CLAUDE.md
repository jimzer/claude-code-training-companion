# Agents Demo

This folder demonstrates Claude Code custom agents (`.claude/agents/`).

## What's here
- `sample_app.py`: a small app with intentional issues for agents to find
- `.claude/agents/`: three custom agents
  - `security-reviewer.md`: read-only security review (plan mode)
  - `test-runner.md`: runs and reports on tests
  - `refactor-advisor.md`: suggests refactors (worktree isolation)
