# Context Management

This station is an interactive feeling-it exercise, not a runnable artifact.

## What's here
- `bloat.md`: prompts to paste that deliberately fill the context window
- `.claude/agents/explorer.md`: a read-only subagent that returns only a concise summary

Run from the repo root checkout so the sibling `../demo-app` is reachable.
Use `/context` to inspect the token breakdown, `/compact` to summarize, `/clear` to reset.
